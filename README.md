# Loan Default & Credit Risk Analysis

## Project Overview
This project focuses on analyzing loan applications, borrower information, loan defaults, and credit risk using data analytics tools.

The objective is to identify loan default patterns, understand borrower risk, and generate meaningful insights to support better lending decisions.

## Tools & Technologies
- SQL – Data querying and analysis
- Python – Data cleaning, analysis, and visualization
- Microsoft Excel – Data analysis and charts
- Tableau – Interactive dashboard development

## Project Analysis
- Loan default analysis
- Loan intent analysis
- Loan grade analysis
- Loan amount and interest rate analysis
- Credit risk analysis
- Borrower risk patterns

## Tableau Dashboard
The interactive dashboard includes:
- Total Loans
- Defaulted Loans
- Default Rate
- Average Loan Amount
- Loan Intent Analysis
- Loan Grade Distribution
- Loan Amount vs Interest Rate
- Loan Risk Heatmap
